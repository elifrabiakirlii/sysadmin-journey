# sysadmin-journey

İTÜ Bilgi İşlem Daire Başkanlığı (BİDB) sistem ofisinde öğrenci olarak çalışırken tuttuğum sistem yönetimi öğrenme günlüğü. Her hafta bir konu, bir proje.

🌐 Haftalık loglar: [web.itu.edu.tr/kirli22](https://web.itu.edu.tr/kirli22/)

## Yol haritası

| Faz | Haftalar | Konu |
| --- | --- | --- |
| 0 | Hafta 0 | Git ve GitHub'a başlangıç |
| 1 | Hafta 1–4 | Linux, izinler, ağ temelleri, ağ teşhisi |
| 2 | Hafta 5–8 | SSH, Nginx, PowerShell ve Active Directory, script otomasyonu |
| 3 | Hafta 9–12 | Docker, Ansible, izleme, yedekleme |
| 4 | Hafta 13–16 | Güvenlik, bulut ve bitirme projesi: mini kampüs altyapısı |

## Klasör yapısı

- `hafta-01/` … `hafta-16/`: Haftalık notlar ve küçük scriptler
- `projeler/`: Haftalardan çıkan bağımsız projeler
- `notlar/`: Kopya kağıtları (Linux komutları, ağ araçları, PowerShell)

## Not

Tüm çalışmalar kendi lab ortamımda (sanal makineler) yapılıyor. Bu repoda kuruma ait IP adresi, sunucu adı, kullanıcı verisi ya da iç doküman bulunmaz.
